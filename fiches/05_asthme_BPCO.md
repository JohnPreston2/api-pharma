# Asthme & BPCO
> Niveau officine · Tier 1 · Mise à jour 2026

---

## Chiffres clés
| | Asthme | BPCO |
|---|---|---|
| Prévalence | 4 millions en France | 3 millions (sous-diagnostiquée) |
| Cause principale | Atopie / allergènes | **Tabac** (> 90%) |
| Réversibilité | **OUI** (bronchospasme) | **NON** (obstruction fixée) |
| Objectif traitement | Contrôle des symptômes | Ralentir progression + qualité de vie |

---

## Physiopathologie (l'essentiel)

```
ASTHME                              BPCO
Inflammation bronchique             Inflammation chronique (tabac)
  ↓                                   ↓
Hyperréactivité bronchique          Emphysème + Bronchite chronique
  ↓                                   ↓
Bronchospasme RÉVERSIBLE            Obstruction IRRÉVERSIBLE
  ↓                                   ↓
Sifflement, dyspnée                 Toux productive, dyspnée d'effort
```

**Différence clé en spirométrie :**
- Asthme : VEMS/CV < 0,70 + **réversibilité > 12%** après bronchodilatateur
- BPCO : VEMS/CV < 0,70 **post-bronchodilatateur** (irréversible)

## Classification

### Asthme — Contrôle (GINA 2024)
| Niveau | Symptômes diurnes | Réveil nocturne | Limitation activité |
|---|---|---|---|
| **Contrôlé** | ≤ 2/semaine | Aucun | Non |
| **Partiellement contrôlé** | > 2/semaine | 1/semaine | Minime |
| **Non contrôlé** | Quotidiens | Fréquents | Majeure |

> Si Ventoline > 2 × / semaine → **traitement de fond insuffisant**

### BPCO — Classification GOLD
| Stade | VEMS (% théorique) | Symptômes |
|---|---|---|
| GOLD 1 — Léger | ≥ 80% | Souvent asymptomatique |
| GOLD 2 — Modéré | 50–79% | Dyspnée effort, toux |
| GOLD 3 — Sévère | 30–49% | Dyspnée faible effort |
| GOLD 4 — Très sévère | < 30% | Dyspnée repos, IRC |

## Les dispositifs inhalés — Le piège n°1 officine

| Dispositif | Exemples | Technique requise |
|---|---|---|
| **MDI** (aérosol doseur classique) | Ventoline, Becotide, Atrovent | **Coordination** inspiration lente + appui simultané |
| **Autohaler** (MDI autodéclenché) | Airomir | Inspiration déclenche l'aérosol automatiquement |
| **Turbuhaler** | Symbicort, Pulmicort | Inspiration **profonde et forcée** (cliquetis de chargement) |
| **Diskus** | Séretide, Flixotide | Inspiration **lente et profonde** (glisser + inhaler) |
| **Respimat** | Spiriva, Striverdi | Nuage lent, peu de coordination requise |
| **Breezhaler** | Onbrez, Seebri | Capsule perforée, bruit normal pendant inhalation |
| **Ellipta** | Trelegy, Relvar | Inspiration profonde, 1 clic = 1 dose |

### Technique universelle (MDI avec chambre)
```
1. Agiter l'inhalateur
2. Expirer complètement (vider les poumons)
3. Placer l'embout / chambre en bouche
4. Appuyer et inspirer LENTEMENT (3–5 secondes)
5. Apnée 10 secondes
6. Expirer par le nez
```

> **Chambre d'inhalation** : à proposer systématiquement si coordination difficile (enfants, personnes âgées, mauvaise technique)

**À chaque dispensation → DÉMONTRER / VÉRIFIER LA TECHNIQUE**

## Interactions majeures à l'officine

| Association | Risque | Conduite |
|---|---|---|
| **β-bloquants non cardio-sélectifs** (propranolol) | **Bronchospasme** | CI absolue asthme / BPCO sévère |
| **β-bloquants cardio-sélectifs** (bisoprolol, métoprolol) | Risque moindre mais vigilance | Utiliser si indispensable (post-IDM), surveiller |
| **AINS / aspirine** | Crise asthme (aspirine-sensibilité ~10%) | Interroger antécédent à chaque dispensation |
| **Corticoïdes oraux prolongés** | Immunodépression, ostéoporose, diabète | Supplémentation Ca/Vit D, surveillance glycémie |
| **Anticholinergiques + atropiniques** (TCA, antihistaminiques) | Effets anticholinergiques cumulés | Rétention urinaire, sécheresse |

## Conseil officinal — Les 3 réflexes

1. **Ventoline > 2×/semaine** → signal d'alarme → fond insuffisant → médecin
2. **Rinçage bouche après CSI** → toujours, systématique → candidose oropharyngée évitable
3. **BPCO : arrêt tabac** → seule intervention qui modifie réellement l'évolution → orienter vers aide au sevrage

**Signes d'exacerbation asthme → urgence si pas de réponse SABA en 15 min :**
Sifflement + dyspnée + cyanose + impossibilité de parler → **appel SAMU**

## Ce que dit le patient 🗣️

| Ce qu'il dit | Ce que ça signifie |
|---|---|
| *"ma Ventoline, mon aérosol"* | SABA de secours (évaluer fréquence d'utilisation) |
| *"je siffle la nuit / au réveil"* | Asthme non contrôlé → fond à renforcer |
| *"je tousse le matin avec des glaires"* | **BPCO** probable (tabagique) → spirométrie? |
| *"mon Symbicort je le prends comment, fond ou crise ?"* | Stratégie MART → expliquer l'inhalateur double usage |
| *"j'ai oublié comment on fait avec le Turbuhaler"* | Démonstration + fiche technique à donner |
| *"depuis les nouveaux cachets pour le cœur j'essouffle plus"* | β-bloquant non cardiosélectif → vérifier la molécule |
| *"j'ai une infection pulmonaire"* | Exacerbation BPCO → antibiotique + corticoïdes courts |

## Pièges génériques ⚠️

- **Salbutamol** (Ventoline) : génériques disponibles, technique identique
- **Fluticasone/salmétérol** (Séretide) : génériques Airflusal, Iffeza → même dispositif Diskus, OK
- **Tiotropium** (Spiriva) : génériques Handihaler ou Respimat → **dispositifs différents** selon version → vérifier
- **Budésonide/formotérol** (Symbicort) : génériques Bufomix, DuoResp → OK mais vérifier Turbuhaler vs Nexthaler
- Jamais substituer sans vérifier que le patient maîtrise le nouveau dispositif
