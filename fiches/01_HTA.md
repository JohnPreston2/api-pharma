# HTA — Hypertension Artérielle
> Niveau officine · Tier 1 · Mise à jour 2026

---

## Chiffres clés
| | |
|---|---|
| Prévalence | ~12 millions de Français traités |
| 1ère cause | de mortalité cardiovasculaire mondiale |
| Cible PA | < 130/80 mmHg (< 140/90 si âgé > 80 ans) |

---

## Physiopathologie (l'essentiel)

```
PA = Débit cardiaque × Résistances périphériques
      ↑ FC / Volume         ↑ vasoconstriction
           ↓
    Activation SRAA + tonus sympathique ↑
           ↓
  Organes cibles : cœur · reins · cerveau · rétine
```

**3 mécanismes clés à retenir :**
- SRAA activé → rétention Na+/H2O → volume ↑
- Sympathique ↑ → vasconstriction + FC ↑
- Vieillissement → rigidité artérielle (HTA systolique isolée du sujet âgé)

---

## Diagnostic & Classification

| Grade | PA systolique | PA diastolique |
|---|---|---|
| Normale haute | 130–139 | 85–89 |
| HTA grade 1 | 140–159 | 90–99 |
| HTA grade 2 | 160–179 | 100–109 |
| HTA grade 3 | ≥ 180 | ≥ 110 |

**Automesure :** seuil ≥ 135/85 mmHg (règle des **3×3** : 3 mesures matin + 3 mesures soir, 3 jours consécutifs)

---

## Classes thérapeutiques

| Classe | DCI clés | Posologie type | Surveiller |
|---|---|---|---|
| **IEC** | ramipril, périndopril, énalapril, lisinopril | Ramipril 2,5–10 mg/j | Kaliémie, créatinine, **toux sèche** |
| **ARA2 (Sartans)** | valsartan, irbesartan, losartan, candésartan, olmésartan | Selon molécule | Kaliémie, créatinine (pas de toux) |
| **ICa dihydropyridines** | amlodipine, félodipine, lercanidipine | Amlodipine 5–10 mg/j | **Œdèmes MI** (fréquents, bénins) |
| **ICa non-DHP** | vérapamil, diltiazem | Selon forme | **CI si β-bloquant** (BAV) |
| **Diurétiques thiazidiques** | hydrochlorothiazide, indapamide | Indapamide 1,5 LP/j | Kaliémie, natrémie, uricémie, glycémie |
| **β-bloquants** | bisoprolol, métoprolol, aténolol, nébivolol | Bisoprolol 2,5–10 mg/j | FC, bronchospasme, glycémie masquée |

### Associations préférentielles (HAS 2023)
```
Bithérapie :    IEC (ou ARA2) + ICa  ← combinaison de 1er choix
Trithérapie :   IEC + ICa + Thiazidique
                    ↑
              Si échec → ajouter spironolactone

❌ JAMAIS : IEC + ARA2 (double blocage SRAA → IRA)
❌ JAMAIS : Vérapamil/Diltiazem + β-bloquant (BAV sévère)
```

---

## Interactions majeures à l'officine

| Médicament ajouté | Risque | Action |
|---|---|---|
| **AINS / ibuprofène** | ↓ effet antihypertenseur + IRA avec IEC/ARA2 | Alerter, limiter durée |
| **K+ épargnant** (spironolactone) + IEC/ARA2 | Hyperkaliémie | Contrôle biologique |
| **Vérapamil + β-bloquant** | BAV, bradycardie sévère | CI absolue |
| **Lithium + thiazidique** | Toxicité lithium | Signaler au prescripteur |

---

## Conseil officinal — Les 3 réflexes

1. **Toux sèche sous IEC** → c'est lui, switcher ARA2 → en parler au médecin
2. **Œdèmes cheville sous amlodipine** → fréquent, surélevation jambes, réassurant mais à signaler
3. **Ne jamais arrêter brutalement les β-bloquants** → rebond hypertensif, risque angineux

**À proposer systématiquement :** appareil automesure (remboursé sur ordonnance), fiche règle des 3×3

---

## Ce que dit le patient 🗣️

| Ce qu'il dit | Ce que ça signifie |
|---|---|
| *"mes cachets pour la tension"* | Traitement antihypertenseur (demander la liste complète) |
| *"j'ai du 18/11 ce matin"* | HTA grade 2 → urgence si symptômes |
| *"depuis le nouveau cachet j'ai une toux"* | IEC → proposer signalement au médecin |
| *"j'ai les chevilles qui gonflent"* | ICa dihydropyridine probable |
| *"j'ai arrêté les cachets, je me sentais bien"* | Risque rebond → réexpliquer maladie chronique |
| *"mon médecin a ajouté un 3ème médicament"* | Trithérapie → vérifier observance avant d'escalader |

---

## Pièges génériques ⚠️

- **Périndopril arginine ≠ périndopril erbumine** → les mg ne sont PAS équivalents (4 mg erbumine = 5 mg arginine)
- Olmésartan : entéropathie sévère rare (malabsorption, diarrhées chroniques → signaler)
- Amlodipine : nombreux génériques, substitution OK sans problème
