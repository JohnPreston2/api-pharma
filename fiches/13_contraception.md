# 13 — Contraception

## Définition
Ensemble des méthodes visant à prévenir une grossesse non désirée. En France : 96% des femmes en âge de procréer utilisent une contraception.

## Mécanismes d'action
- **Œstrogènes** : inhibition FSH → blocage folliculogenèse → pas d'ovulation
- **Progestatifs** : inhibition LH → blocage ovulation + épaississement glaire cervicale + atrophie endomètre
- **DIU cuivre** : toxicité spermatozoïdes + modification endomètre
- **Barrière physique** : préservatif (seule méthode protégeant IST)

## Indice Pearl (efficacité)
- Pilule (usage parfait) : 0,1 / usage courant : ~3-9
- DIU/Implant : 0,1-0,2 (méthodes LARC les plus efficaces)
- Préservatif masculin : 2-15 (courant)
- Spermicide seul : 15-28

## Stratégie contraceptive

```
Jeune femme sans facteur de risque CV
    → EP ou microprogestative selon préférence

ATCD CV, tabac > 35 ans, migraine avec aura, allaitante
    → Microprogestative SEULE ou DIU (hormonal ou cuivre)

Désir contraception longue durée (LARC)
    → DIU LNG (Mirena/Kyleena) ou implant ou DIU cuivre

Rapport non protégé
    → CU : LNG ≤ 72h · EllaOne 72-120h · DIU cuivre ≤ 5j
```

## Interactions majeures
| Médicament | Interaction | Conduite |
|-----------|-------------|---------|
| Inducteurs enzymatiques (rifampicine, phénytoïne, topiramate, carbamazépine) | ↓ Efficacité contraception hormonale | Préservatif + DIU non hormonal |
| EllaOne + pilule progestative | Compétition récepteur → CU inefficace | Arrêt microprogestative · DIU cuivre ou LNG |
| EP + AINS | ↑ Risque thrombose modéré | Paracétamol préférable |

---

## 3 Réflexes Officine
1. **Oubli pilule EP** : < 12h → prendre immédiatement ; > 12h → prendre + préservatif 7j + évaluer CU si rapport dans les 5 derniers jours
2. **EllaOne > Norlevo si > 72h** → toujours demander l'heure exacte du rapport avant de conseiller la CU
3. **DIU cuivre = CU la plus efficace** (>99%) jusqu'à 5j + reste en place pour contraception longue durée

## Vocabulaire patient
| Ce que dit le patient | Ce que ça cache | Réponse |
|----------------------|-----------------|---------|
| "J'ai oublié ma pilule hier soir" | Fenêtre : EP = 12h · désogestrel = 12h · LNG microval = 3h | Heure oubli ? Calculer risque · CU si rapport dans 5j |
| "Je suis sous Cerazette et j'ai pris EllaOne" | EllaOne est un modulateur récepteur progestérone → antagonise Cerazette = CU inefficace | Arrêt Cerazette + DIU cuivre ou avis médecin |
| "Mon antiépileptique marche-t-il avec ma pilule ?" | Topiramate, phénytoïne, carbamazépine = inducteurs → efficacité pilule réduite | DIU non hormonal recommandé |
