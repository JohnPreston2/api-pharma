# Douleur — Paliers OMS & Douleur Neuropathique
> Niveau officine · Tier 1 · Mise à jour 2026

---

## Chiffres clés
| | |
|---|---|
| Fréquence | 1ère cause de consultation en médecine générale |
| Automédication | Paracétamol + ibuprofène = top 3 OTC |
| Risque principal | Surdosage paracétamol, AINS sans IPP, opioïdes + BZD |

---

## Classification de la douleur

```
NOCICEPTIVE          NEUROPATHIQUE           MIXTE
(lésion tissulaire)  (lésion nerveuse)    (ex: lombalgie chronique)
Brûlure, coupure     Brûlures, chocs         Fréquente en pratique
Bien localisée       électriques, fourmil.
Répond aux paliers   Répond POCO aux paliers
                     → Antiépileptiques/ATD
```

## Les 3 Paliers OMS

### PALIER 1 — Douleur légère (EVA 1–4)

#### Paracétamol ← À privilégier systématiquement

| | Adulte standard | Terrain fragile |
|---|---|---|
| Dose | 1 g toutes 6h | 500 mg toutes 6h |
| Max/jour | **4 g** | **3 g** (âgé, < 50 kg, alcool, IRC, IHC) |
| Délai action | 30–60 min | |

**Hépatotoxicité :** seuil thérapeutique/toxique étroit → vérifier les associations (Bi-Profénid, Doliprane, Dafalgan = même molécule !)

#### AINS — En 2ème intention ou douleur inflammatoire

| DCI | Princeps | Dose OTC max | Points clés |
|---|---|---|---|
| Ibuprofène | Advil · Brufen · Générique | 400 mg × 3/j (1200 mg/j) | Avec repas, durée < 5 jours en automédication |
| Kétoprofène | Profenid · Générique | 50 mg × 3/j | Photosensibilisation +++ |
| Naproxène | Apranax · Générique | 250–500 mg × 2/j | Meilleur profil CV que ibuprofène |
| Diclofénac | Voltarène · Générique | 25–50 mg × 3/j | Forme gel topique très utilisée |

**Contre-indications absolues AINS :**
- Ulcère gastrique actif
- IRC sévère (DFG < 30)
- Insuffisance cardiaque décompensée
- Grossesse ≥ 6 mois (**fœtotoxique**)
- Allergie aspirine/AINS
- Anticoagulants (risque hémorragique majeur)

---

### PALIER 2 — Douleur modérée (EVA 4–6)

#### Tramadol

| | |
|---|---|
| Mécanisme | Opioïde faible + inhibiteur recapture 5-HT/NA |
| Posologie | 50–100 mg × 3–4/j · Max **400 mg/j** |
| LP (Topalgic LP) | 100–200 mg × 2/j ou 100–300 mg × 1/j |
| Effets indésirables | Nausées (fréquentes) · Vertiges · Constipation · Seuil épileptogène ↓ |

**Interactions tramadol :**
- ISRS / triptans → **syndrome sérotoninergique**
- IMAO → **CI absolue**
- BZD + alcool → dépression respiratoire

#### Codéine (toujours en association paracétamol)

| | |
|---|---|
| Mécanisme | Prodrogue → morphine (CYP2D6) |
| Exemples | Efferalgan codéiné, Codoliprane, Dafalgan Codéiné |
| Posologie | 30–60 mg/prise, 4–6 prises/j |
| **CI absolues** | Enfant < 12 ans · Allaitantes · Métaboliseurs ultra-rapides (risque surdosage) |

---

### PALIER 3 — Douleur intense (EVA 7–10)

#### Morphine — Référence

| Forme | Exemples | Usage |
|---|---|---|
| Libération prolongée | Skénan LP, Moscontin | Douleur de fond, 2 prises/j |
| Libération immédiate | Actiskenan, Sévrédol | Douleur de fond + interdoses |

**Effets indésirables opioïdes (tous paliers 3) :**

```
CONSTIPATION ← SYSTÉMATIQUE → Laxatif dès J1 (Macrogol, lactulose)
Nausées/vomissements (début traitement, passager)
Sédation (titration progressive)
Dépression respiratoire (surdose)
Dépendance physique (arrêt progressif obligatoire)
```

#### Autres opioïdes forts

| DCI | Produit | Particularité officine |
|---|---|---|
| Oxycodone | Oxycontin, Oxynorm | Rotation opioïde si morphine mal tolérée |
| Fentanyl patch | Durogésic | Changement 72h · T° application ≤ 30°C · Élimination patch usagé !! |
| Hydromorphone | Sophidone | Rotation si opioïdes forts inefficaces |
| Nalbuphine | Nubain | Injectable · Urgences |

**Fentanyl patch à l'officine :**
- Vérifier la zone d'application (pas sur peau irradiée, cicatrice)
- Fièvre → absorption ↑ → risque surdosage
- Collecte patch usagé obligatoire (résidu actif)

## Douleur Neuropathique — Hors paliers OMS

> **Les paliers OMS sont PEU EFFICACES sur la douleur neuropathique**

| Classe | DCI | Princeps | Posologie | Surveiller |
|---|---|---|---|---|
| **Antiépileptiques** | Prégabaline (Lyrica) | 75–300 mg × 2/j | Sédation, vertige, dépendance |
| | Gabapentine | 300–3600 mg/j | Titration progressive |
| **Antidépresseurs** | Duloxétine (Cymbalta) | 60–120 mg/j | Nausées initiales, PA |
| | Amitriptyline | 10–75 mg/j au coucher | Somnolence, anticholinergiques |
| **Topiques** | Lidocaïne patch (Versatis) | 1–3 patchs/j, 12h on / 12h off | Allergie locale |
| | Capsaïcine patch 8% | Application 60 min, spécialiste | Brûlure transitoire |

---

## Interactions majeures à l'officine

| Association | Risque | Conduite |
|---|---|---|
| **AINS + anticoagulants** | Hémorragie digestive | Éviter ou IPP + surveillance INR |
| **AINS + IEC/ARA2 + diurétique** | **Triplette mortelle** → IRA aiguë | Alerter si automédication AINS |
| **Tramadol + ISRS** | Syndrome sérotoninergique | Surveillance, préférer paracétamol |
| **Opioïdes + BZD/alcool** | Dépression respiratoire | Renforcer éducation, naloxone si haut risque |
| **AINS + corticoïdes** | Ulcère gastrique | IPP systématique |

---

## Conseil officinal — Les 3 réflexes

1. **Vérifier le paracétamol "caché"** → Bi-Profénid, Antarène, Doliprane, etc. → additionner les doses
2. **AINS en automédication** → systématiquement : âge, rein, cœur, anticoagulants, grossesse
3. **Opioïdes** → laxatif prescrit en même temps ? Sinon le proposer (Macrogol systématique)

## Ce que dit le patient 🗣️

| Ce qu'il dit | Ce que ça signifie |
|---|---|
| *"j'ai mal, je peux prendre doliprane avec mon traitement ?"* | Vérifier les associations cachées (médicaments complexes) |
| *"c'est des brûlures / des chocs électriques la nuit"* | **Neuropathique** → paliers OMS insuffisants |
| *"mes cachets de morphine ne font plus effet"* | Tolérance → signaler médecin, ne pas augmenter seul |
| *"j'ai arrêté la morphine d'un coup car plus de douleur"* | Syndrome de sevrage → réexpliquer arrêt progressif |
| *"mon patch fentanyl chauffe au soleil"* | T° ↑ absorption → risque surdosage → zone couverte |
| *"depuis la chimio j'ai des fourmis dans les pieds"* | Neuropathie chimio-induite → signaler oncologue |

## Pièges génériques ⚠️

- Paracétamol 1g : nombreux génériques OK — attention aux formulations pédiatriques (mg/mL ≠)
- Tramadol LP : vérifier dose (100/150/200 mg) — ne pas écraser
- Prégabaline : nombreux génériques depuis 2022, substitution OK
- Fentanyl patch : génériques existent (Ratiopharm, Sandoz) → technique identique
